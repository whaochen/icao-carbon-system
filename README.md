# icao-carbon-system
# ✈️ ICAO 航空貨運碳排放與航程距離自動化計算系統

本系統針對企業溫室氣體盤查（ISO 14064-1 範疇三上下游運輸）與產品碳足跡（ISO 14067）需求開發，自動介接聯合國國際民航組織 **ICAO Carbon Emissions Calculator (`https://icec.icao.int/`)**，實現 ERP 空運資料自動清洗轉譯、雙軌碳排計算及官方佐證截圖打包。

---

## 📊 一、 查證方法學與雙軌計算公式說明

本系統以 ICAO 官方計算機之 **1 KG 標準貨重（Shipment Weight = 1 KG）** 作為基準擷取各航線之官方參數與畫面截圖，並於匯出報表中同時提供以下兩種國際認可之計算結果：

### 1. 延噸公里法（Ton-km, tkm）— 適用環境部碳足跡係數 / GLEC 架構
* **航程距離來源：** 採用 ICAO 官方計算之 `Total Trip Distance (KM)`（已含大圓距離與航管繞飛修正）。
* **計算公式：**
  $$\text{延噸公里 (tkm)} = \text{報告期本產品出貨總量 (公噸)} \times \text{ICAO 航程距離 (KM)}$$
  *(註：使用者可再依目標查證標準，將算得之 `tkm` 乘以台灣環境部碳足跡資訊網或英國 DEFRA 公告之航空貨運排放係數 $\text{kg CO}_2\text{e}/\text{tkm}$)*。

### 2. ICAO 官方機隊油耗直接計算流
* **單位碳排來源：** 採用 ICAO 依實際航線機型組合、客貨肚艙分攤比與載貨率算出之 `Total shipment CO2 (KG / 1 KG cargo)`。
* **計算公式：**
  $$\text{ICAO 總碳排 (kg CO}_2\text{)} = \left(\text{報告期本產品出貨總量 (公噸)} \times 1000\right) \times \text{ICAO 1KG 單位碳排 (kg CO}_2\text{/kg)}$$

## 🗺️ 二、 機場代碼轉譯與鄰近國際樞紐備援原則（保守性與完整性原則）

針對 ERP 原始出貨明細中之起訖點名稱，系統透過 `airports_dict.csv` 自動解析括號內之 IATA 三碼並轉譯為 **ICAO 標準四碼**。若遇二線城市或國內線專用機場於 ICAO 國際資料庫無直飛航班紀錄時，系統遵循盤查實務之「鄰近主力國際轉運樞紐替代原則」自動轉譯，並於快取資料庫備註欄明確標示：

| ERP 原始標註機場 | 原始代碼 (IATA / ICAO) | 轉譯查詢之國際樞紐 (ICAO) | 轉譯與替代合理性說明 |
| :--- | :--- | :--- | :--- |
| **日本_大阪_大阪(ITM)** | `ITM` / `RJOO` (伊丹) | **`RJBB`** (大阪關西國際機場) | 伊丹 (`RJOO`) 為日本國內線專用機場，跨國空運貨物實務上皆由同都會區之關西國際機場 (`RJBB`) 起降。 |

## 🚀 三、 系統操作步驟（Web 介面）

1. 開啟本系統之 Streamlit Web 網址。
2. 於 **「步驟 1」** 將 ERP 匯出之原始 Excel 檔（如 `空運.xlsx`）直接拖曳上傳，無須手動刪除首列或修改表頭。
3. 確認畫面自動對應之「起飛地（`運輸起點`）」、「目的地（`運輸終點`）」與「重量（`報告期本產品出貨總量(噸)`）」欄位無誤。
4. 點擊 **「🚀 開始執行快取比對與產出雙軌報表 + 截圖包」**。
5. 點擊 **「📥 一鍵下載完整成果包 (.ZIP)」**，即可獲得：
   * `ICAO_空運碳排與延噸公里計算總表.xlsx`（含 594 筆明細之完整雙軌計算結果）
   * `官方佐證截圖/` 資料夾（內含所有對應航線之 ICAO 官網 Summary 截圖 `.png` 檔）
